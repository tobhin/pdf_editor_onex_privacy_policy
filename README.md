# PDF TOOL ONE - PRIVACY POLICY

DE (Deutsch):

Diese App verarbeitet alle Dokumente ausschließlich lokal auf Ihrem Gerät. Es findet keine Übertragung Ihrer Dateien an den Entwickler, Server oder Dritte statt. Die Schwärzung sensibler Daten (Namen, E-Mails, Telefonnummern, Adressen, Bankdaten etc.) erfolgt vollständig offline. Zugriff wird nur auf Funktionen benötigt, die Sie aktiv nutzen: Kamera (Bildaufnahme zur Schwärzung), Speicherzugriff (Dokumente laden/speichern), Dateizugriff (Dokumente aus anderen Apps empfangen). Exportierte Dateien verbleiben in Ihrem Besitz; das Teilen oder Hochladen in Clouds liegt in Ihrer Verantwortung. Eine Weitergabe personenbezogener Daten erfolgt nur, wenn Sie freiwillig Kontakt per E-Mail aufnehmen (pdf.tool.one@gmail.com
).

UK (English):

This app processes all documents exclusively on your device. Your files are never transmitted to the developer, any server, or third parties. The redaction of sensitive data (names, emails, phone numbers, addresses, banking data, etc.) is performed entirely offline. Access is required only for features you actively use: camera (capturing images for redaction), storage access (loading/saving documents), file access (receiving documents from other apps). Exported files remain in your possession; sharing or uploading them to cloud services is your responsibility. Personal data is shared only if you voluntarily contact us by email (pdf.tool.one@gmail.com
).
